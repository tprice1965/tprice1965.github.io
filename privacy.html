Privacy policy

Last updated: November 7, 2026

Nest Peak Guard is a personal tool used only by its owner, on the owner's own computer, with the owner's own Google account.

Information accessed

With the owner's permission, Nest Peak Guard reads the following from the Google Smart Device Management API for the Nest thermostats the owner selects: device name and room, online status, ambient temperature, humidity, thermostat mode, temperature setpoints, Eco settings and heating/cooling status.

How it is used

This information is used only to record a log of thermostat readings on the owner's own computer, for the owner's own energy monitoring.

Storage

Readings and the Google access token are stored only in files on the owner's computer. Nothing is stored on any server operated by Nest Peak Guard, because there is none.

Sharing

No information is sold, shared, transferred or disclosed to any third party, and none is used for advertising.

Google API Services User Data Policy

Nest Peak Guard's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time in the Google Home app or at myaccount.google.com/permissions. Deleting the files on the owner's computer removes all stored data.

Nest Peak Guard is a personal, non-commercial tool and is not affiliated with or endorsed by Google or Nest.
